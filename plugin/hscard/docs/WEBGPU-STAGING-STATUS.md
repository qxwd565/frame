이름 메시·폰트는 첫 실제 프레임 출력 뒤 시작합니다. 별도 스켈레톤 이미지는 없습니다.

가져온 날짜별 원본 JSON은 WordPress 백그라운드 작업으로 캐시합니다.
캐시된 문서를 게시글 HTML에 포함해 브라우저의 첫 카드 API 왕복을 제거합니다.
날짜별 계산은 기존 공용 JavaScript 코드 하나로 수행하며, 현재 카드 목록 정보로
과거 희귀도·종족을 대체하지 않습니다. 본문 출력 중 원격 HTTP 요청은 없습니다.
관리자 진입 시 기존 가져오기 목록도 한 번 예약합니다. 캐시 누락·손상 시에는
기존 정확한 API 경로를 사용합니다. 백그라운드 실행에는 WordPress cron이 필요합니다.

Windows/Chrome의 새 프로필 3회, 동일한 4장·로컬 원본 리소스·공개 카드 API,
각 fetch에 100ms를 더한 조건의 중앙값입니다. 이 비교는 HTML 문서 캐시 없이
측정하여 프레임 준비 순서 변경만 비교했습니다.
