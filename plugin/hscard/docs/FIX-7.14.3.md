# HScard WebGPU 7.14.3 — WGSL clamp 타입 수정 (시험용)

- 증상: 화면에는 `WebGPU 셰이더 오류`가 표시됨. 이 메시지는 WGSL 컴파일 또는 GPU 파이프라인 생성 실패를 묶은 분류이므로, 정확한 실행 오류는 각 카드의 `title`과 브라우저 개발자도구 콘솔에서 확인해야 함.
- 확인된 결함: GLSL에서는 허용되는 `clamp(vecN, 0.0, 1.0)`이 WGSL에서는 일관된 `vecN<f32>` 인자를 요구함.
- 수정: 명확하게 추론 가능한 벡터 clamp의 2, 3번째 인자에 `vecN<f32>` 생성자를 적용. **693건**, 총 **1,052개 프로그램 유지**. 그 외 셰이더 계산식은 건드리지 않음.
- 7.14.2의 벡터 swizzle 다중 대입 분리, 신형 JSON 전용 API 처리는 유지.
- 제한: 실제 WebGPU 디바이스로 1,052개 셰이더 전수 컴파일 및 화면 일치 테스트는 이 실행 환경에서 수행하지 못했음. 이 변경으로 모든 오류가 해결됐다는 뜻이 아님.
- 페이지에서 계속 `WebGPU 셰이더 오류`가 나오면 개발자도구 콘솔 첫 `[HScard WEBGPU_SHADER] WGSL compile failed ...` 메시지 또는 카드에 마우스 올리면 표시되는 `title` 원문을 확인해야 함.
- 프로덕션 사이트에는 적용하지 말고 독립 시험용 워드프레스에만 설치할 것.
